# UI Context

**Không áp dụng.** Dự án chỉ có API, không có giao diện web.
Giao diện duy nhất là Apollo Sandbox có sẵn khi mở `http://localhost:4000` bằng trình duyệt — không tùy biến.

Nếu sau này thêm giao diện, bổ sung file này (theme, màu, font, component) **trước** khi tạo unit giao diện.
